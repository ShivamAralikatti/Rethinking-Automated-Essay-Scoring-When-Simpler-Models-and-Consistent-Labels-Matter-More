# Revisiting Quadratic Weighted Kappa in Automated Essay Scoring

This repository contains the experimental notebooks accompanying the paper **“Revisiting Quadratic Weighted Kappa in Automated Essay Scoring: Correcting Evaluation Errors and Proposing a Feature-Enriched Alternative.”**

## Paper

- **Authors:** Shivam Anand Aralikatti and Manoranjan Dash
- **Conference:** 2026 IEEE International Conference on Electronics, Computing and Communication Technologies (CONECCT)
- **Location and dates:** Bangalore, India, 2–5 July 2026
- **Pages:** 1–5
- **DOI:** [10.1109/CONECCT68978.2026.11700591](https://doi.org/10.1109/CONECCT68978.2026.11700591)
- **IEEE Xplore:** [Document 11700591](https://ieeexplore.ieee.org/document/11700591)

## Summary

The paper revisits a previously reported Quadratic Weighted Kappa (QWK) result for automated essay scoring and identifies an evaluation issue caused by pooling essays across prompts instead of averaging prompt-specific QWK scores. After correcting the evaluation, it presents a simpler Word2Vec and Random Forest approach that outperforms the corrected baseline.
